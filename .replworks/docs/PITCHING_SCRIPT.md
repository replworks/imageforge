## 1. 30초 버전

이미지 크기·포맷 변환과 CDN 전송을 **한국 사업자가 한국 방식으로 쓸 수 있게** 만든 서비스입니다. 기술은 오픈소스(imageproxy)와 Cloudflare를 그대로 씁니다. 파는 것은 기술이 아니라 **책임**입니다: SLA, 장애 시 연락 가능한 사람, PG 영수증.

## 2. 문제

- **[추론]** 이미지 리사이징은 거의 모든 웹서비스에서 반복되는 작업이고, 직접 만들면 서버 부하와 캐시 관리가 따라온다.
- **[추론]** 해외 이미지 CDN은 원화 결제, 국내 영수증/세금계산서, 한국어 지원에서 소규모 사업자에게 마찰이 있을 수 있다.
- **[미확인]** 위 두 가지를 실제로 겪는 고객이 누구인지, 얼마나 되는지.

## 3. 해결 방식

- URL 파라미터로 리사이징·포맷 변환 (`w`, `h`, `q`, `f`)
- Cloudflare 엣지 캐시로 전송
- 이미지 교체 시 **purge**로 즉시 갱신 (고객이 URL에 버전을 붙일 필요 없음)
- 운영자용 purge 화면 (`cdn.repl.net/purge`, Cloudflare Access 보호)

## 4. 왜 지금 이 방식인가

- **[출처]** "Buy before Build" 원칙: 엔진은 imageproxy를 쓰고 직접 만들지 않는다.
- **[출처]** 혼자 운영 가능한 구조: 로그인은 DB 없이 Cloudflare Access, 인프라는 Cloudflare에 위임.
- **[추론]** 구현 비용이 낮으므로 틀렸을 때 잃는 것도 작다.

## 5. 차별점

- **[출처]** 유료 한국 서비스의 가치 = 책임 소재, SLA, PG 영수증.
- 기술 차별화는 없다. 이 점을 숨기지 않는다. 차별화가 운영·계약·결제에만 있다는 것이 이 피치의 핵심 주장이자 가장 약한 고리다.

| "Cloudflare Images/Cloudinary 쓰면 되지 않나?" | 기능은 겹친다. 한국 결제·영수증·한국어 대응·책임 소재가 필요 없는 고객에게는 그쪽이 맞다. 필요한 고객만 대상이다. |
